# Portal EBD

Frontend do portal de gestão da Escola Bíblica Dominical (React, Vite, TypeScript).

## Desenvolvimento

```bash
npm install
npm run dev
```

Aplicação em `http://localhost:8080` (porta configurada no Vite).

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run preview` — preview do build
- `npm test` — testes (Vitest)
- `npm run lint` — ESLint
